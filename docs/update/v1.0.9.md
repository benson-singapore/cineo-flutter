## 版本简介

## 更新内容

### 版本检查与更新信息

- 保留 GitHub Releases API 作为首选版本来源。
- API 请求失败、限流或返回异常时，回退到公开 Releases Atom feed 获取最新 tag。
- 根据 tag 从 raw.githubusercontent.com 获取对应的中文更新说明。
- 增加版本服务检查失败状态，界面不再一直停留在“正在检查更新”。
- 补充 API 限流、Atom feed、更新日志请求顺序和失败状态测试覆盖。

## Bug 修复

- 修复部分网络环境下 GitHub API 返回 `403` 后无法检测到 `v1.0.9` 的问题。
- 修复版本检查失败时缺少明确错误反馈的问题。

## 构建与发布说明

- Android：GitHub Actions 将使用内部构建号 `6` 重建 Release APK。
- iOS：GitHub Actions 将使用内部构建号 `6` 重建未签名 IPA。
- 本说明不预先声明本次重建的 CI 结果；最终状态以 `v1.0.9` 对应的 GitHub Actions workflow 和 GitHub Release 资产为准。
