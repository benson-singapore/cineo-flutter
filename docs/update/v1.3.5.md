# Cineo 1.3.5 更新说明

**版本**：1.3.5+12
**发布日期**：2026年10月11日

## 概览

本次更新聚焦 TMDB 匹配精度与播放体验：手动匹配支持指定 TMDB 季数，应用内画中画改用全局悬浮窗并防止手势误退，同时修复继续观看栏目的重复占位问题。

## 新增功能

### TMDB 按季匹配（580564e）

- 为 TMDB 匹配结果增加 `matchedSeason` 字段，并在缓存编解码、详情拉取与本地化链路中透传。
- 手动匹配弹窗支持加载所选剧集的季列表、选择对应季并确认；电影或不指定季数时保持原有行为。
- 详情页按所选季展示标题后缀（第 X 季）、季简介、季海报与来源年份，并收敛季选择器与剧集封面回退逻辑。
- 所选季在 TMDB 详情中不存在时拒绝保存，避免写入无效覆盖。

### 应用内画中画重构（b5a72fb）

- 小窗改用 root overlay 承载，呼出小窗时恢复竖屏约束，返回播放页时恢复横竖屏自适应。
- 新增路由级 `preventPop` 能力，画中画期间拦截返回手势并移除下方详情路由，保持播放器与视频控制器存活。
- 详情页返回改用 `removeRoute`，避免误弹播放路由导致小窗销毁。
- 小窗补充倍速切换入口，关闭与返回时正确清理悬浮层与方向锁定。

## 问题修复

- **继续观看去重（b044b10）**：继续观看按“类型 + 标题”分组，每部标题仅保留最新一条未看完记录，与播放历史页分组口径一致，避免多集进度重复占位。
