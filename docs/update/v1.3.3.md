# Cineo v1.3.3 更新说明

## 版本信息

- **版本号**：`v1.3.3`
- **内部构建号**：`10`
- **更新时间**：2026-09-13（计划发布时间，Asia/Singapore）
- **版本类型**：新版本
- **更新范围**：`v1.3.2..HEAD`

## 版本简介

本次版本重点改进播放页交互、播放进度保存、资源站搜索和片库来源配置，提升跨资源站播放的连续性，并支持按视频源调整片库封面比例。

## 更新内容

- 支持播放页渐进式搜索其他资源站，搜索结果可持续追加显示。
- 增加按视频源配置片库封面比例，支持竖屏和横屏布局，并同步应用到首页、片库、搜索和分类浏览页面。
- 改进 MacCMS 分类响应解析，兼容更多分类字段、嵌套结构和独立分类接口。
- 增加分类配置刷新能力，保留用户已设置的启用状态；远端分类暂时不可用或返回空结果时保留本地配置。
- 改进来源切换后的片库、搜索和封面布局刷新流程。
- 升级本地数据库到 v12，新增视频源封面模式持久化，并兼容旧数据库迁移。

## Bug 修复

- 修复播放返回或播放器关闭前播放进度可能未及时保存的问题（`5fa06d6`、`f718839`）。
- 修复浮动播放器和画中画界面的外部点击穿透问题（`d359eb6`、`b6285b4`）。
- 修复播放加载状态下导航控件显示不稳定的问题（`4bad7af`）。
- 增加播放资源搜索封面显示，改善渐进式资源搜索结果的识别（`3394d6a`）。
