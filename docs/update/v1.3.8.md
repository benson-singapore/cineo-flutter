# Cineo v1.3.8

计划发布日期：2026-11-21（新加坡时间）

## 概述

改进观看历史、播放进度恢复和 Hub 跨端同步。

## 新功能与变更

- 同步设置增加旧冲突操作清理入口，并调整页面操作间距。
- 增加跨端隔离 HTTP 同步测试及准备说明。

## 修复

- 按来源和剧集身份匹配播放进度，避免错误恢复。
- 保护手机观看记录的推送与重建，清理 Hub 已删除的剧集进度。
- 补全跨端观看记录的年份和分类。

## 构建与发布

计划由 GitHub Actions 构建 Android APK 和未签名 iOS IPA，内部构建号为 15。
