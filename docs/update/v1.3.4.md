# Cineo 1.3.4 更新说明

**版本**：1.3.4+11  
**发布日期**：2026年9月19日

## 概览

本次更新主要针对播放器功能进行了重要改进，新增了自动旋转和手势控制功能，同时优化了媒体详情界面的展示效果。

## 新增功能

### 播放器增强
- **自动旋转功能**：视频播放器现在支持根据设备方向自动旋转，提升全屏观看体验
- **手势控制**：新增手势控制功能，支持更直观的播放器操作
- **播放器指示器**：添加了播放器状态指示器，用户可清晰了解播放状态

### 历史记录管理
- **隐藏单个视频**：在播放历史中支持隐藏单个视频项，用户可自主管理历史记录

## 优化改进

- **剧集预览组件**：将媒体详情页的剧集预览重构为独立滚动视图，改善了大量剧集场景下的性能和交互体验
- **媒体详情界面**：针对详情页进行了全面优化，提升了整体的响应速度和用户体验

## 文档更新

- 更新了项目许可证信息
- 补充了数据库忽略规则文档
