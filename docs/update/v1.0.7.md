# Cineo v1.0.7 更新说明

## 版本信息

- **版本号**：`v1.0.7`
- **内部构建号**：`5`
- **更新时间**：2026-08-23 19:38:44（Asia/Singapore，计划发布提交时间）
- **版本类型**：功能更新
- **更新范围**：`v1.0.6..HEAD`

## 版本简介

Cineo v1.0.7 聚焦于系统播放器和画中画体验，补充 Android 与 iOS 的系统级播放入口，并同步更新项目文档和预览内容。

## 更新内容

### 系统播放器与画中画

- 在 iOS 中增加系统播放器打开能力，并重构画中画入口，使用原生 `AVPlayer` 和 `AVPictureInPictureController` 直接启动画中画。
- 在 Android 中增加系统播放器打开能力，播放器控件支持跳转系统播放器。
- 更新播放器控件提示文本，并回传画中画开始、失败和结束状态。
- 移除不再使用的 `url_launcher` 依赖。

### 应用更新

- 更新应用更新页面的 GitHub Release 下载链接逻辑。
- 增加打开 GitHub Release 页面行为的测试覆盖。

### 项目文档

- 重构中文 README 内容和结构，补充项目 Logo、功能亮点、技术栈、环境要求、配置说明及预览截图。
- 新增英文 README，并调整首页、搜索页和播放页预览图片的展示顺序。

## Bug 修复

- 修复 iOS 画中画无法直接启动的问题：创建原生播放器后等待画中画条件满足，再自动启动并处理成功、失败和结束状态。

## 构建与发布说明

- Android：GitHub Actions 将使用内部构建号 `5` 构建 Release APK。
- iOS：GitHub Actions 将使用内部构建号 `5` 构建未签名 IPA。
- 修复发布脚本在仅有 release note 未跟踪时的同步恢复处理，确保版本发布流程可以正常继续。
- 本说明不预先声明构建或测试结果；最终状态以 `v1.0.7` 对应的 GitHub Actions workflow 和 Release 资产为准。
