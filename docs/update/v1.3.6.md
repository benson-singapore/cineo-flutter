# Cineo v1.3.6

发布时间：计划于 2026-11-20，实际时间以 GitHub Release 为准。

## 概述

新增 Cineo Hub 设备云端同步与手机协助电视输入，并改进影片信息匹配和视频源设置。

## 新功能与变更

- 支持 Cineo Hub 设备绑定和云端同步。
- 手机前台可接收电视搜索输入请求，并可在设置中手动检查有效会话。
- 支持接收 Hub 下发的 TMDB 配置；手动匹配影片时默认带入年份。

## 修复

- 设置默认视频源时移除重复回调。
- 拒绝缺少主机名的视频源地址。

## 构建与发布说明

计划由 GitHub Actions 构建 Android APK 和未签名 iOS IPA；实际构建与发布结果以工作流为准。
