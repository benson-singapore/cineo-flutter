## 版本简介

本次版本增加默认资源站配置导入能力，帮助用户快速载入预置的 MacCMS 资源站，并在导入后自动选择合适的默认资源站。

## 更新内容

- 在资源站导入弹窗中增加“加载默认配置”按钮，提供 20 个预置资源站配置。
- 导入默认配置后优先将如意资源设为默认资源站。
- 当配置中没有如意资源时，自动回退到第一个有效资源站。
- 保留现有 JSON 校验、HTTP 站点开关和导入提示流程。
