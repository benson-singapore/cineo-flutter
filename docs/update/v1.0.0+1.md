## 版本简介

Cineo v1.0.0+1 是项目的首个版本，提供以本地数据为中心的 Flutter 影视发现与播放体验。应用支持多视频源配置、影视浏览与搜索、详情和剧集播放、收藏与观看记录，并集成 TMDB 元数据增强和应用锁能力。

## 更新内容

### 核心体验

- 新增首页、搜索、分类浏览和影视详情页面。
- 支持影视剧集、单集导航、播放控制和播放来源切换。
- 支持 HLS（`.m3u8`）与 MP4 播放。
- 支持继续观看、观看历史、收藏和本地媒体库。
- 支持 Android 画中画播放。
- 完成 Cineo 品牌视觉、应用图标和深色主题界面。

### 视频源与内容发现

- 支持添加、编辑、启用/禁用、收藏、删除和测试视频源。
- 支持 MacCMS 兼容 API、资源站 JSON 配置导入和远程视频源浏览。
- 支持视频源分类、分页搜索、分类列表和默认来源管理。
- 支持记录同一影视的来源偏好，并对来源健康状态进行处理。

### TMDB 数据增强

- 新增 TMDB Token 安全保存和媒体元数据客户端。
- 支持影视详情、演员、季、单集简介以及海报和背景图增强。
- 新增 TMDB 元数据与图片本地缓存、缓存统计、过期清理和手动匹配。

### 安全与本地数据

- 新增 PIN 应用锁、失败尝试退避锁定和后台返回宽限期。
- 支持单独管理成人标记视频源，并由应用锁保护显示开关。
- 使用 SQLite 保存视频源、收藏、观看进度、搜索历史和来源偏好。
- 使用安全存储保存应用锁验证信息和 TMDB Token。

### 平台与发布

- 完成 Android、iOS 和 Web 工程基础配置。
- Android 支持 multidex 和原生画中画能力。
- 增加本地 Android 自签名构建、未签名 iOS IPA 构建和 GitHub Actions 构建流程。
- 支持通过版本 tag 自动触发 Android APK 与未签名 iOS IPA 构建。

## Bug 修复

- 修复收藏和观看历史无法正确持久化的问题。
- 修复分类树未正确映射到叶子分类 ID 的问题。
- 修复 HTML 格式的影视简介展示异常的问题。
- 修复视频源响应不稳定时默认来源处理异常的问题。
- 修复视频列表缺少海报可用字段的问题。
- 修复大响应数据读取过程中连接过早关闭的问题，并增加相关诊断信息。
- 修复 Android 多媒体依赖导致的 multidex 构建问题。
