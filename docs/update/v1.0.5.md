# Cineo v1.0.5 更新说明

## 版本信息

- **版本号**：`v1.0.5`
- **内部构建号**：`5`
- **更新时间**：2026-08-23 12:25:04（Asia/Singapore，计划发布提交时间）
- **版本类型**：功能更新
- **更新范围**：`v1.0.4..HEAD`

## 版本简介

Cineo v1.0.5 聚焦于媒体详情加载、播放器体验、搜索与媒体库操作，并完善 TMDB 元数据、M3U8 播放处理和版本更新说明展示。

## 更新内容

### 详情页与 TMDB 元数据

- 优化详情页打开流程，优先展示已有本地数据和 TMDB 预取结果。
- 将 TMDB 元数据拆分为预览、基础详情和 enrichment 阶段，减少首次进入详情页的等待时间。
- 在页面打开后继续加载演员、剧集和集数信息，并兼容旧版 TMDB 缓存数据。
- 统一媒体打开流程，增加异步加载状态和重复操作保护。

### 播放器

- 新增 M3U8 广告片段过滤能力，并增加设置页面中的过滤选项。
- 改进 M3U8 代理播放处理，代理失败时回退到原始播放地址。
- 增加播放器手势交互和 iOS 原生播放器支持。
- 支持 iOS 画中画相关播放器控制。

### 首页、搜索与媒体库

- 首页优先使用 TMDB 海报，并打通首页搜索入口。
- 增加媒体库和搜索页面的回到顶部操作，并调整按钮位置以避免被底部导航遮挡。
- 优化分类浏览、搜索结果和媒体库条目的加载状态及媒体打开流程。

### 更新说明与界面体验

- 使用 Markdown 渲染版本发布说明，支持标题、列表、链接等内容。
- 优化长发布说明的预览、展开和收起行为，避免内容溢出。
- 调整详情页、分类页和底部导航布局，改善内容展示空间。

## Bug 修复

- 修复 M3U8 代理播放失败时无法继续使用原始播放地址的问题。
- 修复回到顶部操作在搜索和媒体库页面中位置不合适或被导航区域遮挡的问题。
- 修复分类页面与底部导航布局导致的内容显示问题。
