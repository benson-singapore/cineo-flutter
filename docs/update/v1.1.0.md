# Cineo v1.1.0 更新说明

## 版本信息

- **版本号**：`v1.1.0`
- **内部构建号**：`7`
- **更新时间**：2026-08-29（计划发布时间，Asia/Singapore）
- **版本类型**：新版本
- **更新范围**：`v1.0.9..HEAD`

## 版本简介

本次版本完善视频源分组配置与数据同步能力，优化首页分类加载和视频源切换体验，并为媒体详情补充观看进度、续播和 TMDB 媒体信息支持。

## 更新内容

### 视频源分组与片库同步

- 新增视频源分组配置同步，支持同步远程视频源的原生叶子分类。
- 支持根据启用的分组过滤浏览和搜索中的分类及媒体项目。
- 简化成人资源分组配置为平面列表，并采用轻量级按需加载模式。
- 增加数据库分组配置表的结构修复和旧版数据迁移处理。
- 切换默认视频源后自动刷新片库数据。

### 首页与媒体详情

- 重构首页分类轨道加载逻辑，单个分类加载失败时不会阻塞其他轨道。
- 新增观看进度记录和续播支持。
- TMDB 媒体模型补充类型和发布日期字段，并适配电影与 TV 节目的日期数据。

## Bug 修复

- 修复数据库升级后可能缺失视频源分组配置表的问题。
- 修复旧版分组配置列名不一致时无法完成结构迁移的问题。
- 修复首页单个分类请求失败可能影响其他分类加载的问题。

## 构建与发布说明

- Android：GitHub Actions 将使用内部构建号 `7` 构建 Release APK。
- iOS：GitHub Actions 将使用内部构建号 `7` 构建未签名 IPA。
- 本说明不预先声明本次发布的 CI 结果；最终状态以 `v1.1.0` 对应的 GitHub Actions workflow 和 GitHub Release 资产为准。
