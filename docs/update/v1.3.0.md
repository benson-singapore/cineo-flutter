# Cineo v1.3.0 更新说明

## 版本信息

- **版本号**：`v1.3.0`
- **内部构建号**：`8`
- **更新时间**：2026-09-12（计划发布时间，Asia/Singapore）
- **版本类型**：新版本
- **更新范围**：`v1.2.0..HEAD`

## 版本简介

本次版本增强播放器画中画体验，并优化多资源站搜索。播放中的视频可以在应用内以可移动、可缩放的悬浮窗口继续播放，也可以在离开应用时自动进入系统画中画；资源站搜索则改为渐进式返回结果，让用户更快看到已找到的内容。

## 更新内容

### 应用内与系统画中画

- 新增应用内悬浮播放器，支持拖拽移动和双指缩放播放窗口。
- 悬浮窗口支持单击显示或隐藏播放控制，并提供暂停、快进、快退、关闭和返回播放详情操作。
- Android 在用户离开应用时通知 Flutter 自动进入系统画中画。
- 结合 Flutter 生命周期和原生画中画状态回调，在视频播放期间自动切换系统画中画。
- 从系统画中画返回应用后恢复播放详情页、当前播放位置和播放状态。

### 多资源站搜索

- 搜索其他资源站时按并发请求逐个返回匹配结果和搜索进度。
- 资源站选择面板立即打开，并持续追加已完成搜索的结果。
- 搜索过程中展示已查询数量和进度，过滤成人资源站并保留当前资源站。
- 补充仓库层和媒体详情页的渐进式搜索测试。

### 文档与配置说明

- 更新 README 和英文 README 中的应用截图路径。
- 增加基础资源站配置说明。
