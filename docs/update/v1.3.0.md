# Cineo v1.3.0 重建说明

## 版本信息

- **版本号**：`v1.3.0`
- **内部构建号**：`8`
- **更新时间**：2026-09-12（重建发布时间，Asia/Singapore）
- **版本类型**：当前版本重建
- **更新范围**：`v1.3.0..81a34e5`

## 版本简介

本次重建修复 iOS 系统画中画无法正常打开的问题，并完善应用内悬浮播放器的缩放边界与双击放大操作。

## 更新内容

### 画中画稳定性与交互

- 优化 iOS 原生画中画播放器图层的视图层级绑定，使其附着在可见的播放器区域。
- 增加视频播放项目的 `readyToPlay` 状态检查，避免在播放器尚未准备完成时启动画中画。
- 延长 iOS 画中画可用状态的等待时间，并在启动失败时清理相关资源。
- 修复应用内悬浮窗口双指缩放的宽度边界，确保窗口不会超出屏幕。
- 增加双击悬浮窗口放大到屏幕最大可用宽度的操作，并在放大后保持窗口位于安全区域内。

## Bug 修复

- 修复 iOS 上点击系统画中画后可能显示“无法打开画中画”的问题。
- 修复应用内画中画窗口缩放计算的边界条件问题。

## 构建与发布说明

- iOS：GitHub Actions 将使用公开版本 `1.3.0` 和内部构建号 `8` 重新构建未签名 IPA。
- 本说明不预先声明本次发布的 CI 结果；最终状态以 `v1.3.0` 对应的 GitHub Actions workflow 和 GitHub Release 资产为准。
