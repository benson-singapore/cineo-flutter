## 版本简介

Cineo v1.0.6 聚焦于系统级画中画播放体验、首页离线恢复能力和首页滚动导航，提升视频播放连续性以及网络不稳定时的可用性。

## 更新内容

### 播放器与画中画

- 增强 Android 系统级画中画支持，提供播放/暂停操作并同步当前播放状态和画面比例。
- 启用播放器后台播放，处理画中画模式切换和紧凑播放器界面展示。
- 更新 Dart 与 Android 之间的画中画通信模型，并补充相关测试覆盖。

### 首页离线缓存

- 将首页分类 rails 和媒体快照保存到本地数据库，支持数据库版本升级。
- 首页刷新时先恢复本地快照，再获取远程内容并保存最新结果。
- 保留收藏、观看进度和搜索历史等用户状态，并增加缓存恢复测试。

### 首页导航

- 为首页接入滚动控制器，并在滚动离开顶部后显示回顶按钮。
- 统一首页与媒体库的回顶操作和按钮展示逻辑。
- 增加首页滚动状态变化的 widget 测试。
