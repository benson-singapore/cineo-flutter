# v1.3.9

## 版本

- 版本号：v1.3.9（构建号 16）
- 发布时间：2026-11-22
- 上一版本：v1.3.8
- 覆盖范围：`v1.3.8..v1.3.9`

## 概述

改进视频源封面信息，便于查看剧集进度、评分和内容类型。

## 新功能与变更

- 封面显示来源提供的集数、更新和完结状态，并显示有效评分。
- 根据可识别的来源分类展示电影、剧集、动漫、短剧和综艺标签。
- 详情缺少状态字段时保留同一媒体的已知状态；来源明确提供空状态时清除旧值。

## 修复

- 修复详情数据缺少状态字段时可能丢失已有封面状态的问题。

- 发布流水线生成 Android APK 与未签名 iOS IPA。
- 本日志随版本提交，由发布流水线用作 Release 正文。
