# Cineo v1.3.7

## 版本

- 版本号：1.3.7；内部构建号：14
- 发布日期：2026-11-21（以 GitHub Release 为准）
- 上一版本：v1.3.6

## 概述

修复云端同步设备绑定时 PIN 输入后按钮状态不刷新的问题。

## 新功能与变更

- PIN 输入限制为最多 8 位数字。

## 修复

- 输入满 8 位数字后启用绑定按钮，删除至不足 8 位时重新禁用。

## 构建与发布说明

- 计划通过 GitHub Actions 构建 Android APK 和未签名 iOS IPA；实际结果以工作流为准。
