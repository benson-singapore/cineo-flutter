# Cineo v1.0.4 更新说明

## 版本信息

- **版本号**：`v1.0.4`
- **内部构建号**：`4`
- **更新时间**：2026-08-22 18:43:50（Asia/Singapore，计划发布提交时间）
- **版本类型**：功能更新
- **更新范围**：`v1.0.0+3..HEAD`

## 版本简介

Cineo v1.0.4 聚焦于应用锁、视频源管理、播放历史和版本更新体验，同时完善 iOS 界面、详情页交互以及 GitHub Actions 发布流程。

## 更新内容

### 应用锁与设置

- 新增独立的应用锁设置和立即锁定入口。
- 支持在设置中连接和管理应用锁相关功能。
- 未主动设置 PIN 时不再强制要求启动验证。
- 清理设置页面中重复的应用锁控制项。

### 视频源与媒体库

- 新增视频源搜索能力。
- 优化成人视频源开关和成人分类页的显示逻辑。
- 从片库中移除收藏入口，收藏内容继续通过收藏功能管理。
- 内置默认视频源配置得到完善。

### 播放与更新体验

- 播放历史展示剧集和播放详情。
- 新增 GitHub Releases 版本检查和版本更新入口。
- 支持检测远端最新版本，并跳转到项目 Releases 页面下载更新包。

### 界面体验

- 优化影视详情页的海报布局和返回按钮位置。
- 优化个人页面设置列表的间距和信息密度。
- 优化 iOS 分组设置界面、圆角表面和自适应玻璃效果底部导航栏。
- 优化底部导航栏布局，避免内容被悬浮导航栏遮挡。

### 发布流程

- 增加 Cineo 发布 skill 和 release notes skill 的计划版本支持。
- Makefile 区分公开版本号和内部构建号，支持新版本发布与当前版本重建。
- 完善 GitHub Actions 的 Android APK 和未签名 iOS IPA 构建及 Releases 发布流程。

## Bug 修复

- 修复关闭成人视频源后仍显示成人视频源的问题。
- 修复关闭成人内容后成人分类标签仍显示的问题。
- 修复详情页返回按钮位置不符合预期的问题。
- 修复启动时未设置应用锁却进入 PIN 验证的问题。
- 修复内容区域可能被底部浮动导航栏遮挡的问题。

## 构建与发布说明

- Android：GitHub Actions 将构建 Release APK；未配置固定发布证书时使用临时自签名证书。
- iOS：GitHub Actions 将构建未签名 IPA，下载后可使用合法企业账号重新签名和安装。
- GitHub Actions 构建和 Release 资产上传结果以本次 `v1.0.4` workflow 为准。
