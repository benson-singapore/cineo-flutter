# Cineo v1.0.8 更新说明

## 版本信息

- **版本号**：`v1.0.8`
- **内部构建号**：`5`
- **更新时间**：2026-08-24 22:21:12（Asia/Singapore，计划发布提交时间）
- **版本类型**：功能更新与问题修复
- **更新范围**：`v1.0.7..HEAD`

## 版本简介

Cineo v1.0.8 优化 iOS 画中画播放流程，并新增 Cineo 官方产品展示网站。同时修复网站功能卡片的布局偏移与对齐问题。

## 更新内容

### 画中画播放体验

- 重构 iOS 画中画播放器的初始化、播放器层挂载和资源清理流程。
- 使用 Flutter 主视图控制器承载画中画播放器层，确保 iOS 能够接受画中画请求。
- 增加画中画启动失败和结束后的清理逻辑，避免播放器层与控制器资源残留。
- 在进入系统播放器或 iOS 画中画前暂停 Flutter 内部播放，并保留当前播放状态处理。

### Cineo 官方网站

- 新增基于 React、Vite 和 Tailwind CSS 的 Cineo 官方静态展示网站。
- 增加 Cineo 品牌资源、真实应用截图、功能介绍和项目下载入口。
- 补充网站独立开发与生产构建配置，可部署到 GitHub Pages、Vercel、Cloudflare Pages 或其他静态文件服务器。
- 更新网站页脚署名，并完善功能卡片在不同布局下的对齐表现。

## Bug 修复

- 修复网站功能卡片在布局中出现偏移、对齐不一致的问题，重置相关偏移样式并强制统一卡片对齐方式。
- 修复 iOS 画中画启动流程中的播放器初始化和视图挂载问题，增加启动失败、结束及超时路径的资源清理。

## 构建与发布说明

- Android：GitHub Actions 将使用内部构建号 `5` 构建 Release APK。
- iOS：GitHub Actions 将使用内部构建号 `5` 构建未签名 IPA。
- 网站：生产构建命令为 `npm run build`，产物输出到 `website/dist/`。
- 本说明不预先声明构建或测试结果；最终状态以 `v1.0.8` 对应的 GitHub Actions workflow 和 GitHub Release 资产为准。
