# Cineo v1.2.0 更新说明

## 版本信息

- **版本号**：`v1.2.0`
- **内部构建号**：`7`
- **更新时间**：2026-08-30（计划发布时间，Asia/Singapore）
- **版本类型**：新版本
- **更新范围**：`v1.1.0..HEAD`

## 版本简介

本次版本新增视频缓存下载与本地播放能力，支持从媒体详情发起下载、在下载管理页查看任务，并在网络不可用时播放已完成的本地缓存。同时优化剧集库、搜索和媒体详情体验，并补充播放器快进控制。

## 更新内容

### 缓存下载与本地播放

- 新增 HLS 下载任务模型、播放列表解析、下载存储目录、本地服务和并发下载服务。
- 支持下载任务持久化、分片断点续传、缓存统计、失败重试、暂停与取消。
- 新增下载管理页面，并从个人页和设置页提供下载入口及下载配置。
- 支持从媒体详情发起缓存任务，已完成的缓存可通过本地 HLS 服务播放。
- 播放器支持本地文件和本地 HLS 播放，并保留远程播放回退逻辑。

### 媒体浏览与播放器

- 剧集库新增排序功能，并增加返回顶部操作。
- 播放器增加前进和后退十秒控制。
- 搜索与分类浏览支持传递片库图片比例，使详情页封面展示保持一致。

### 官网下载说明

- 官网新增下载说明页面和应用截图预览，补充新版本功能展示。

## Bug 修复

- 修复媒体详情页信息展示问题。
- 修复切换默认视频源后片库未重置的问题。
- 修复分类详情页未正确传递图片比例的问题。

## 构建与发布说明

- Android：GitHub Actions 将使用内部构建号 `7` 构建 Release APK。
- iOS：GitHub Actions 将使用内部构建号 `7` 构建未签名 IPA。
- 本说明不预先声明本次发布的 CI 结果；最终状态以 `v1.2.0` 对应的 GitHub Actions workflow 和 GitHub Release 资产为准。
